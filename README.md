FRIDAY Voice Assistant
FRIDAY is a Python-based virtual assistant that enables hands-free system control and web navigation through voice commands. The project integrates speech recognition and text-to-speech synthesis to create a seamless human-computer interface.

Core Functionalities

Voice Interface: Uses SpeechRecognition to process audio and pyttsx3 for verbal feedback.

Web Automation: Instant voice-triggered access to YouTube and Spotify.

Knowledge Retrieval: Real-time Wikipedia searching and automated summary reading.

Environmental Tuning: Dynamic energy threshold adjustment to filter background noise.

Tech Stack

Language: Python

Libraries: SpeechRecognition, pyttsx3, wikipedia, webbrowser

Installation

Clone the repository.

Install dependencies: pip install speechrecognition pyttsx3 wikipedia.

Ensure PyAudio is configured for your operating system.

Execute python assistant.py to start the assistant.
